**Client:** Takeda, Switzerland  
**Role:** Enterprise Cloud / Data Platform Engineer   
**Period:** August 2021 – December 2025   
**Technology:** AWS, Amazon EKS, Kubernetes, CloudFormation, GitHub Enterprise, GitHub Actions  

### The project

The platform supported enterprise analytics and data science workloads running across multiple AWS accounts and Amazon EKS clusters.

The focus was on building and operating reliable, secure and maintainable cloud infrastructure while improving automation, standardization and operational efficiency.

### My role

I worked across the complete platform lifecycle, from infrastructure provisioning and configuration through day-to-day operations, upgrades, troubleshooting, production support and controlled changes.

### What I did

- Designed, built and operated AWS-based platforms supporting production analytics and data science workloads.

- Owned Amazon EKS platforms including setup, configuration, maintenance, upgrades, troubleshooting and production support.

- Worked extensively with AWS IAM roles and policies to provide secure and governed access to cloud resources.

- Managed AWS networking using VPCs and security groups.

- Worked with S3, EC2 and managed database instances as part of the platform infrastructure.

- Used CloudFormation to standardize and automate infrastructure provisioning and configuration.

- Used GitHub Enterprise to manage infrastructure configuration and CloudFormation templates.

- Built GitHub Actions workflows to automate infrastructure deployments with review and approval steps.

- Used CloudWatch and CloudTrail for monitoring, troubleshooting and investigation of infrastructure activity.

- Worked with CloudFront and WAF to support secure application and platform access.

- Worked with Lambda, API Gateway and Glue as part of application and data platform capabilities.

- Supported high-priority production incidents across Kubernetes, AWS infrastructure and platform services.

- Worked with QA and other stakeholders to implement controlled production changes and follow established change-management processes.

- Collaborated with data science, security, infrastructure and platform teams to improve platform usability, stability and operational efficiency.


### Infrastructure and automation

Infrastructure configuration was managed through GitHub Enterprise using version-controlled CloudFormation templates.

GitHub Actions workflows were used to automate deployments following the established review and approval process.

This provided a consistent approach to infrastructure changes:

**Change → Review → Approval → Automated Deployment → Verification**

### Cost optimization

I owned and led a three-month cloud cost optimization program across multiple AWS accounts.

Using **AWS Cost Explorer** and **Apptio Cloudability** reports, I reviewed resource consumption and identified areas where infrastructure and storage could be optimized.

Key activities included:

- Reviewed AWS resource utilization and consumption patterns to identify optimization opportunities.
- Analyzed S3 storage usage and identified redundant and unnecessary storage.
- Streamlined S3 storage and standardized appropriate storage classes.
- Implemented and enforced S3 lifecycle policies to automatically manage data throughout its lifecycle.
- Introduced mandatory tagging to improve resource ownership, cost visibility and governance.
- Worked with platform and application teams to implement the identified optimization measures.

The initiative reduced monthly cloud costs across multiple AWS accounts from approximately **$160K to $90K**, representing a reduction of around **44%**.

Besides delivering substantial recurring savings, the project established better governance around cloud storage.

### Enterprise operations

The platform operated within a regulated pharmaceutical environment.

Infrastructure and platform changes therefore followed established governance and change-management processes.

I worked closely with QA, security, infrastructure, data science and platform teams to coordinate changes, troubleshoot production issues and maintain platform stability.

### Outcome

The platform provided a reliable and standardized AWS foundation for enterprise analytics and data science workloads.

The combination of infrastructure as code, automated deployment workflows, controlled access and operational processes helped improve platform consistency, maintainability and reliability across the environment.
